## Acceptance Criteria

*From `design/game-brief.md` (Features 1, Core loop, First minute, Avoid):*

- [ ] ฉากร้านมุมมอง first person ที่เคาน์เตอร์ ตามภาพอ้างอิงใน `design/ref/`
- [ ] ลูกค้า NPC มาที่เคาน์เตอร์และเล่าปัญหาสภาพอากาศในกล่อง Dialog ด้านล่างจอ (ภาษาอังกฤษ); ข้อมูลลูกค้า 4 คนเก็บเป็น data ไม่ hardcode: Bob (rain → Rainforest), Sprout (wind → Valley), Auntie Skye (sun → Desert), Granny Ruby (snow → Glacier) พร้อมบทพูดภาษาอังกฤษในส่วน "ตัวละคร" ของ `design/game-brief.md`
- [ ] กด/แตะแผนที่บนเคาน์เตอร์แล้วแผนที่ 4 แมพเด้งขึ้นมา (ป่าดิบชื้น หุบเขา ทะเลทราย ภูเขาน้ำแข็ง)
- [ ] เลือกแมพผิด: ไม่มีกล่องยืนยัน ไม่เข้าด่าน แสดงคำใบ้เพิ่มทีละขั้น แล้วให้เลือกใหม่จนถูก
- [ ] เลือกแมพถูก: ขึ้นหน้า Loading (แอนิเมชัน 2D ตามแมพที่ไป) แล้วเข้าสู่ด่าน obby ของแมพนั้น
- [ ] บนเคาน์เตอร์มีสมุด Achievement (เปิดดูได้) และปุ่มเมนูมุมซ้ายบนเปิดหน้า Pause (เสียง All/Music/SFX, Back, Menu กลับหน้าหลัก)
- [ ] กลับมาจากด่านพร้อมขวดอากาศแล้วส่งให้ลูกค้า ลูกค้าแสดงปฏิกิริยาพอใจ แล้วคนถัดไปมา
- [ ] ไม่มีภูตนำทาง
- [ ] ใช้ได้ทั้งเมาส์และการแตะบนมือถือ
