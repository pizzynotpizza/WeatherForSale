**Pitch:** Samที่ต้องเฝ้าร้านขายสภาพอากาศแทนUncle John ต้องกระโดดข้ามด่าน obby แข่งกับเวลาไปดูดอากาศใส่ขวดให้ลูกค้า และตามหา Shard ม่วงเพื่อไปให้ถึง True Ending

**Genre:** ร้านค้า (shop sim) ผสม 3D obby platformer แบบจับเวลา

**Controls:** PC: WASD เดิน, Space กระโดด, เมาส์มองและคลิก, ตอนดูดอากาศเป็น QTE กดรัวๆ ปุ่มคีย์บอร์ดที่สุ่มขึ้นจอ · มือถือ: จอยสติ๊กเสมือนด้านซ้าย, ปุ่มกระโดดด้านขวา, ตอนดูดแตะรัวๆ ตามปุ่มที่ขึ้นตำแหน่งสุ่ม *(guessed ยกเว้นการดูด)*

**Question:** การสลับระหว่างรับออเดอร์ที่ร้าน, กระโดด obby แข่งเวลา และกดรัวๆ ดูดอากาศ สนุกพอให้เล่นวนซ้ำ และลื่นพอบน browser มือถือไหม *(guessed)*

**Hooks:**
- ขายสภาพอากาศเป็นขวด (แดด ฝน หิมะ ลม ม่วง รุ้ง) ลูกค้าแต่ละคนต้องการต่างกัน
- ด่าน obby ธีมตามภูมิอากาศ เลือกจากแผนที่บนเคาน์เตอร์ตามปัญหาของลูกค้า
- จบด่าน obby แล้วต้องกดรัวๆ ดูดอากาศเข้าขวดจนเกจเต็ม 100
- Shard ม่วง 4 ชิ้นซ่อนตามด่าน เก็บครบจะได้ True Ending

**Intent:** staged failure: ตกแล้วกลับ Checkpoint, หมดเวลาแล้ว Game Over (you said)

## Challenge
obby ทุกด่านจับเวลา ตกแล้วเกิดใหม่ที่ Checkpoint ล่าสุด แต่เวลายังเดินต่อ ถ้าหมดเวลาก่อนผ่านด่านจะ Game Over ลูกค้าคนแรกและด่านแรกเผื่อเวลาพอ ด่านหลังๆ เวลาบีบขึ้นและมีสิ่งกีดขวางมากขึ้นตามภูมิอากาศ *(guessed)*

## Core loop
- ลูกค้าเล่าปัญหา แล้วผู้เล่นกดแผนที่บนเคาน์เตอร์เลือก 1 ใน 4 แมพ (ผิดแล้วได้คำใบ้เพิ่ม)
- เล่น obby 2 ด่านของแมพนั้นให้ทันเวลา แล้วกดรัวๆ ดูดอากาศจนเกจเต็ม 100
- กลับร้านส่งขวดให้ลูกค้า แล้วรับลูกค้าคนถัดไป ระหว่างทางหา Shard ม่วงเพิ่ม

## Goal & fail state
- Goal: เก็บ Shard ม่วงครบ 4 ชิ้น แล้วสู้บอส Tempestเพื่อ True Ending (ถ้าไม่ครบจะได้ Normal Ending)
- Fail: หมดเวลาก่อนผ่านด่าน obby = Game Over (เริ่มด่านนั้นใหม่ *(guessed)*), ตกแค่เกิดใหม่ที่ Checkpoint
- Freeplay: ปลดล็อกหลังเคลียร์ Story ครั้งแรก (ตอนจบใดก็ได้); เลือกเล่นทีละแมพ ไม่มีคัตซีน จบเมื่อผ่านแมพนั้น
- ดาว: แมพละ 3 ดาวตามเวลาที่ใช้ผ่าน (รวม 12 ดวง) หน้า Complete แสดงดาว เวลา และ Key Item (Shard) 0/1; เกณฑ์เวลาแต่ละดาว *(provisional — ตัวเลขใน UI beta อ่านไม่ออก ตั้งใน config)*
